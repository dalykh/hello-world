# Infrastructure as Code (IaC)

This directory would contain IaC scripts (e.g., Terraform, AWS CloudFormation)
for provisioning and managing the cloud infrastructure for the SaaS Taxi Suisse application.

Key components to manage:
- VPC, Subnets, Security Groups
- Amazon RDS for PostgreSQL
- Amazon Cognito User Pools
- AWS ECS/EKS or Elastic Beanstalk for backend services
- S3 buckets for static assets and uploads
- CloudFront distributions
- IAM Roles and Policies
- API Gateway (if used)
- Logging and Monitoring (CloudWatch)
